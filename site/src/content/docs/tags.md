Select a recording and its tags appear in the **Details** panel: title, artist, album, album artist, year, track number, genre, comment and cover art.

## One recording

Click a field to change it. To set the artwork, click the cover or drop a PNG or JPEG on it.

## Many at once

Tick the boxes of several recordings (the header box ticks them all) and edit them together. Fields that differ show _Multiple values_ and are only changed if you type in them, so you can set the album and artist for a whole stack without touching the titles.

## ID3 versions

Tags are saved as ID3v2.4 on macOS and Linux, and ID3v2.3 on Windows, because Windows Explorer and Media Player only show cover art from v2.3. Older players and car stereos also prefer v2.3. You can pick the version per recording, or change the default in [Settings](../settings/).

A save never damages the recording, even if it's interrupted.
